# UNO 핀 맵(Pinout) 및 회로 연결 설명

본 모듈은 **Arduino Uno** 보드와 **DS1302 RTC(실시간 시계) 모듈**, 그리고 **식물 성장 LED 릴레이**를 연결하여 시간에 따라 식물 성장용 LED를 자동으로 켜고 끄는 서브 컨트롤러입니다.

---

## 📌 핀 맵 (Pinout Map)

| 연결 모듈 / 부품 | 핀 이름 | 아두이노 우노(UNO) 연결 핀 | 설명 |
| :--- | :--- | :--- | :--- |
| **DS1302 RTC 모듈** | VCC | **5V** | 아두이노 5V 전원 핀 직접 연결 |
| | GND | **GND** | 아두이노 GND 핀 직접 연결 |
| | CLK (SCLK) | **디지털 11번 (D11)** | 시계 클럭 신호 핀 |
| | DAT (I/O) | **디지털 12번 (D12)** | 시계 데이터 입출력 핀 |
| | RST (CE) | **디지털 6번 (D6)** | 리셋 및 치입 핀 (*13번 핀 내장 LED 간섭 회피*) |
| **식물 성장 LED 릴레이** | VCC | **5V** | 릴레이 구동 전원 |
| | GND | **GND** | 공통 접지 |
| | IN (Control) | **디지털 7번 (D7)** | 릴레이 제어 신호 (Active HIGH) |
| | NO / COM | **LED 전원 회로** | 식물 성장 LED 외부 전원 연결 |

---

## ⚡ 회로 연결 시 주의사항

1. **VCC / GND 전원 연결**:
   * RTC 모듈의 VCC와 GND를 일반 디지털 IO 핀에 연결하여 전원을 공급하지 마세요. (전류 부족 및 초기화 실패 원인)
   * 반드시 아두이노의 **5V** 및 **GND** 핀에 직접 연결해야 합니다.

2. **RST(리셋) 핀 선택**:
   * UNO 보드의 13번 핀은 보드 내장 LED(`LED_BUILTIN`) 및 저항과 연결되어 있어 신호 간섭이 발생할 수 있습니다.
   * 따라서 안정적인 RTC 데이터 통신을 위해 **6번 핀**으로 변경하여 사용합니다.

---

## ⏰ 동작 로직 및 시간 설정 방법

### 1) 식물 성장 LED 자동 스케줄
* **07:00 ~ 21:59 (낮 시간대)**: 식물 성장 LED **점등 (ON / HIGH)**
* **22:00 ~ 06:59 (야간 시간대)**: 식물 성장 LED **소등 (OFF / LOW)**

### 2) RTC 최초 시계 맞추기 (시간 설정)
스케치 파일 [uno-rtc-led.ino](./uno-rtc-led.ino)의 `setup()` 함수 내에 설정 코드가 포함되어 있습니다.

```cpp
// [최초 1회 설정 방법]
// 아래 주석을 해제하고 아두이노에 업로드하여 현재 시간을 모듈에 저장합니다.
rtc.writeProtect(false);
rtc.setDOW(WEDNESDAY);   // 요일 설정
rtc.setTime(17, 7, 40);  // 시, 분, 초 설정
rtc.setDate(5, 6, 2024); // 일, 월, 년 설정
rtc.writeProtect(true);
```

> ⚠️ **주의**: 시계 설정이 완료된 후에는 해당 코드 5줄을 **다시 주석 처리하고 재업로드**해야 아두이노가 재부팅될 때마다 시계가 과거 시간으로 리셋되는 현상을 방지할 수 있습니다.
